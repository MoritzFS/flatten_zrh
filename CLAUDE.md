# Task brief

Reproduce https://github.com/almostimplemented/flattensf for Zürich instead of
San Francisco, and publish the resulting site on GitHub Pages
(https://moritzfs.github.io/flatten_zrh/).

## Credit / licensing requirements
- Upstream code is MIT licensed, "Copyright (c) 2026 sf-flat-routes contributors".
  Keep that copyright + permission notice in our LICENSE alongside our own,
  and credit the upstream repo and its authors in the README and on the site.
- Upstream's LICENSE has a "NOTE ON DATA" section; write the Zürich equivalent:
  - OpenStreetMap / Overture street data: (c) OpenStreetMap contributors, ODbL 1.0
    (derived geometry carries share-alike obligations).
  - Elevation: swisstopo (e.g. swissALTI3D) — verify current terms and required
    attribution wording.
  - Neighbourhood boundaries: Stadt Zürich Open Data — verify licence.
  - Any vendored libraries (e.g. Leaflet, BSD-2-Clause) keep their notices.
